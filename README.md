# Notion Embeds

This repository hosts static HTML files via **GitHub Pages** to create clean embeds in Notion without file title bars or banners.

## 🔗 Live Embed Links

Copy this link to paste directly into Notion:

* **Social_Media_Round Widget:** `https://chuck54l.github.com/Notion_Widgets/Social_Media_Round.html`


---

## 🚀 How to Embed in Notion

1. Copy the URL above *(Make sure the capital `QU` matches your filename!)*.
2. Open your Notion page and type `/embed`.
3. Paste the URL and click **Embed Link**.
4. Resize the widget frame as needed using Notion's side handles.
